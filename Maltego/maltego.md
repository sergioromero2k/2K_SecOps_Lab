## Maltego
---
**Maltego** es una **herramienta de ciberseguridad y OSINT (Open Source Intelligence)** que sirve para recolectar, correlacionar y visualizar información de fuentes públicas en Internet.
> Maltego te ayuda a descubrir relaciones ocultas entre personas, dominios, IPs, empresas, correos, redes sociales, etc.
Se representa todo en gráficos visuales, lo que lo hace muy potente para investigaciones.

sudo apt update
sudo apt install maltego
