### recon-ng
---
**recon-ng** es un framework de OSINT en línea de comandos, muy usado en pentesting y reconnaissance.
Se usa para:
* Recolección automática de información pública
* Enumeración de dominios, subdominios, emails, hosts
* Integrar APIs (Shodan, HaveIBeenPwned, Hunter, etc.)
* Guardar todo en una base de datos estructurada.

| Maltego        | recon-ng           |
| -------------- | ------------------ |
| Gráfico        | Terminal           |
| Visual         | Automatizado       |
| Manual         | Scriptable         |
| Ideal análisis | Ideal recon masivo |
